Open-Source Project

Agents: contract-first tooling for reliable coding agents.

A reusable Rails API toolkit that turns engineering rules, verification, and documentation into an explicit operating system for humans and coding agents.

View on GitHub Read the production case study

The problem it solves

Coding agents can generate plausible changes quickly, but speed is not the same as correctness. Teams still need a shared contract for architecture, response formats, authorization, testing, documentation, and the definition of done.

Agents packages that contract as repository-owned files and executable checks. The model does not have to guess how the team works, and reviewers do not have to rediscover the same violations in every pull request.

Repository Contents

A small toolkit with explicit responsibilities

AGENTS.md

Defines the implementation workflow, API contract, hard-fail rules, verification order, and documentation responsibilities.

bin/verify

Runs the required verification profile so local work and CI share one repeatable definition of technical readiness.

bin/contract_audit

Detects contract drift, unsafe shortcuts, route inconsistencies, serializer violations, and documentation-template problems.

Flow / PRD templates

Gives derived documentation a stable structure after implementation and verification are complete.

Typical workflow

  1. Define or update the requirement contract.
  2. Load repository rules and relevant implementation context.
  3. Plan the change and map requirements to tests.
  4. Implement inside the documented Rails conventions.
  5. Run verification and contract audits.
  6. Update Flow, PRD, and changelog artifacts only after the checks pass.
