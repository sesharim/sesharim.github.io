The operating model

Useful AI development is a software-engineering system. The model receives the smallest relevant context, works against a clear contract, uses approved tools, and must produce evidence before a change is considered complete.

  1. Define the contract: expected behavior, interfaces, constraints, and ownership.
  2. Load relevant context: repository rules, requirements, architecture, and nearby implementation patterns.
  3. Plan before editing: map requirements to files, tests, risks, and verification.
  4. Implement with bounded tools: keep model authority explicit and observable.
  5. Verify and audit: run tests, security checks, contract checks, and documentation updates.
